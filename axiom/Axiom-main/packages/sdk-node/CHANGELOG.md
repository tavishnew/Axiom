# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2024-12-29

### Added

- Initial release of `@permix/sdk`
- `Permix` client class with configuration options
- `check()` method for getting full decision results
- `can()` method for boolean permission checks
- `batchCheck()` method for checking multiple permissions
- Built-in caching with configurable TTL
- Custom cache adapter interface for Redis/etc
- Retry logic with exponential backoff
- Debug mode for logging
- Comprehensive TypeScript types
- Full JSDoc documentation
